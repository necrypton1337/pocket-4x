# Pocket 4X (рабочее название)

Пошаговая 4X-стратегия для телефона. Открывается в браузере, работает офлайн, сохраняется после каждого действия.
Сеттинг пока нейтральный: все названия, значки и цифры лежат в `src/core/data.js`.

## Что есть в версии 0.2
- Фантастика: люди и чужие на одной планете. Сейчас играбельны три человеческие фракции:
  Империя, Учёные и Старообрядцы. Четвёртое место занимают «Вольные колонисты» — временная заглушка, пока не придуманы чужие.
- У каждой фракции свой бонус, особый юнит, особое здание и вид городов (см. DESIGN.md).
- Экономика: деньги, содержание армии, покупка, улучшение юнитов, проект «Коммерция».
- Нейтральные поселения с влиянием и бонусами союзнику, местная фауна с гнёздами, руины с находками, особые ресурсы.
- Карта из гексов с туманом войны, 1–3 соперника под управлением ИИ, три уровня сложности.
- Анимации ходов и боя, показ хода соперников, ход юнитом подтверждается кнопкой.
- Победа — уничтожить все крупные фракции, поражение — потерять все свои города.

## Запуск
```bash
npm start        # сервер на http://localhost:8080 и адрес для телефона в той же Wi-Fi сети
npm test         # тесты ядра (node --test, без зависимостей)
npm run sim      # прогон партий ИИ против ИИ
```

Офлайн-режим (service worker) включается только по HTTPS или на localhost. По домашнему Wi-Fi
(http://192.168…) игра работает, но без сети не откроется. Чтобы играть офлайн, нужен HTTPS-хостинг, например GitHub Pages.

После изменения файлов игры увеличьте `VERSION` в `sw.js`, иначе телефон продолжит показывать старую версию из кэша.

## Устройство
- `src/core/` — логика без DOM: `game.js` (правила), `ai.js` (соперники), `turn.js` (смена хода),
  `mapgen.js`, `hex.js`, `rng.js` (детерминированный генератор), `save.js`, `data.js`.
- `src/ui/` — интерфейс: `main.js` (экран, кнопки, жесты), `render.js` (карта на canvas).
- `tests/` — тесты ядра.

Известное упрощение: ИИ видит всю карту и не учитывает туман войны.
